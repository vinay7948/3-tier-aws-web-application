 3-Tier Web Application Deployment on AWS

 Project Overview

Designed and deployed a secure 3-tier web application architecture using AWS services.

 AWS Services Used

- Amazon VPC
- Amazon EC2
- Application Load Balancer (ALB)
- Amazon RDS
- Security Groups
- Route Tables
- Linux
- MySQL
 
 Key Implementations

- Created a custom VPC for the application.
- Configured public and private network components.
- Deployed EC2 instances for the application layer.
- Configured an Application Load Balancer.
- Connected the application layer with an RDS MySQL database.
- Configured security groups and network access controls.
- Tested application and database connectivity.

 Architecture

Internet → Application Load Balancer → EC2 → RDS MySQL

 Technologies

AWS | Linux | MySQL
